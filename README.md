# ERC20 Token with Foundry

This is an ERC20 token project using Foundry for development and testing.

## What's included
- ERC20 token using OpenZeppelin
- Basic manual token implementation
- 23 tests that all pass
- GitHub Actions for automatic testing

## How to use

1. Install Foundry: https://getfoundry.sh/
2. Clone this project
3. Run tests: `forge test`

✅ All 23 tests pass
✅ GitHub Actions runs automatically on every push
